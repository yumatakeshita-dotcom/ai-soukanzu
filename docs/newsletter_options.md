# 週のまとめを配る方法の候補(2026-11-18 作成)

今は「共有リンクのページ」と「リポジトリの .md」まで。外部のサービスにはまだ登録していない。
どれも `newsletter/発行日.md` の文章をそのまま貼れる。

| 方法 | よいところ | 気になるところ | 費用の目安 |
|---|---|---|---|
| **note(おすすめ)** | 日本語の読者が多い。無料で始められ、あとで有料記事やメンバーシップにできる | メールで届けるには読者側のフォローが必要 | 無料(有料記事は手数料あり) |
| Substack | メールで届く。無料・有料の購読を同じ場所で管理できる | 画面が英語。日本の読者にはなじみが薄い | 無料(有料購読は手数料あり) |
| beehiiv | メール配信に強く、紹介制度などで読者を増やしやすい | 画面が英語。無料枠に読者数の上限 | 無料〜 |
| 自分の Gmail で送る | すぐ始められる。営業先・知り合いに個別に送れる | 人数が増えると手作業がつらい。配信停止の仕組みが無い | 無料 |
| 共有リンクのページだけ | 今のまま何もしなくてよい | 読む人が自分で見に来る必要がある | 無料 |

**おすすめ**: まず note で無料公開して反応を見る。読者が増えたら有料のまとめ(業界ごとの深堀りなど)を足す。
手数料や上限は変わることがあるので、登録の前に各サービスの公式ページで確かめる。登録や投稿は持ち主の確認をとってから行う。
