# 定期タスクのモデルと使用量の見方 (2026-11-19)

全16個の定期タスクは、どれもモデルを指定していない(標準のまま)。
既存の定期タスクは「新しい会話を毎回作るタイプ」で、ツールからモデルを変えられない(変えるには作り直しが必要)。
作り直すと実行履歴が消えるため、今回は変えていない。

## 分け方
| 区分 | タスク | 理由 |
|---|---|---|
| 軽いモデルで足りる(haiku候補) | 相関図サイトの公開(Cloudflare) 毎日9:41 | 決まったスクリプトを動かして確認するだけ |
| 同上 | ニュースのリンク直し 毎日9:47 | スクリプトを動かすだけ |
| 同上 | 調査の新着をサイトに追加 毎日9:13 | スクリプト+確認+公開 |
| 同上 | シンガポールの会社 毎月20日 | スクリプトを動かすだけ |
| 同上 | Xアカウント追加 毎日7:07 | x_check.py で確かめた結果を並べる |
| 標準(sonnet)のまま | 毎日更新6:43、引き抜き、お金の流れ、LP・VC、世界企業、深堀り、まだ薄いところ | 調べて出典を確かめる・判断が要る |
| 同上 | 確かめ直し(日曜)、SEC開示ウォッチ、計算資源1枚、週のまとめ、D1人物追加 | 数字・人物の確認や文章が要る |

## 毎週の使用量まとめ
`python3 scripts/usage_report.py` → `inbox/usage/日付.md`(足すだけ)。
正確なトークン数は取れないので、main への commit の回数と inbox/ のファイル数が目安。
正確な使用量は claude.ai の設定の「使用量」で見る。
