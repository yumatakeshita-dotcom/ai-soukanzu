# 装いとブランド(2026/11/21追加・見本版)
メニュー「装いとブランド」。起業家・経営者が公開の場で着ているものと、関係のあるブランドを、出典つきで見せる。

## データは2種類
- 手で確かめた分: `site/data/outfit.js` の `OUTFIT`(採点つき。足すだけ)
- 自動で足す分: `site/data/outfit_auto.js`(`scripts/outfit_merge.py` が `inbox/outfit/` の「合格」から作る。手で直さない)

## 毎朝の流れ(Gemini=探す、機械と Claude=確かめる)
1. `python3 scripts/outfit_research.py daily`(`inbox/outfit/people.txt` の次の2人。1人=Gemini 1回)
2. 出典ページを実際に開き、本人の名前が書いてあるものだけ「合格」。ブランドは本文に名前があるものだけ残す。開けないものは「保留」、名前が無いものは「除外」(理由を記録)
3. `python3 scripts/outfit_merge.py` → `site/data/outfit_auto.js`。公開するときは `data/outfit.js` と `data/outfit_auto.js` も共有リンクに出す

## 守ること
- 画像は保存・転載しない(出典ページへのリンクと、装いの文章だけ)。埋め込みは公式に許されるものだけ(今は使わない)
- 対象は企業家・経営者・公式に紹介されたスタッフの、公開の場の装いだけ。私生活や個人の特定の詮索はしない
- ブランドは本人・報道・ブランド公式が明記したものだけ。写真から当てたブランドは載せない
- 採点は「参考の目安」。人の優劣ではない
- GeminiのGeminiの1日の上限は19回(無料枠20回の範囲内。他の調査と共有)。装いの調査は毎朝のGemini調査の最後に1人分だけ動き(`gemini_research.py daily` から呼ぶ)、上限に達していたら何もしない。日本の起業家から順
