## 0件の係の原因と直したところ
- 見る期間が「過去48時間」と短い → 「過去7日」にした(頻度を下げた分、取りこぼさない)
- 発表ページ・適時開示が、クラウドから開けないことが多い(許可外) → 開けないときは、**2つ以上の別の媒体が同じ名前・数字・日付を伝えていれば**、確かさ「報道」+「本文未確認」で入れてよいことにした(1媒体だけ・食い違うものは今までどおり入れない)。人材係がすでに使っている決まりと同じ
- 探す言葉が狭い → 検索の言葉の例を足した(CAIO・最高AI責任者・Claude 導入・第三者割当増資 など)。日本の提携は大企業だけでなく銀行・商社・自治体・中堅も対象にした
- 日付が先の予定(例: 11/25付で就任予定)は、発表日を date にして、予定日を note に書く

## 見直しの目安(毎週月曜に weekly を見て決める)
- 直近7日で 1回あたり2件以上 → 増やす候補
- 3回以上動いて0件、または5回以上で1件以下 → 減らす候補(機械が出す案。最後は人が決める)
- 減らした係が2週続けて1回あたり2件以上になったら、頻度を戻す
