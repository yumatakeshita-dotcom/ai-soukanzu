# LinkedIn を「手がかり」として使う(2026/11/24)

毎朝の人材の調査(引き抜き・採用・日本人事)で、人の企業名・職歴を探すときの決めごと。

## できること / できないこと
- できない: LinkedIn にログインして自動で巡回すること(利用規約違反で、アカウント停止のおそれがある)。クラウドからは linkedin.com 自体が開けない(2026/11/24に確認)。
- できる: ログインなしで検索結果に出る公開プロフィールの要約(会社名・肩書き)を**手がかり**にして、別の確かな出典で裏を取る。

## 手順
1. WebSearch で「人名 会社名 LinkedIn」「site:linkedin.com/in 人名」を探し、検索結果の要約から会社名・肩書き・時期の候補を得る。
2. その候補を、次のどれかで確かめる。確かめられたものだけを inbox に足す。
   - 会社の公式発表・公式サイトのチーム紹介・IR
   - 信頼できる報道
   - 本人のX・GitHub(`python3 scripts/x_check.py @名前`)
3. 確かめられないものは、`confidence` を「推定」にし、`note` に「LinkedInの検索要約のみ・未確認」と書いて保留にする(相関図に入れる判断は取り込み係に任せる)。
4. 画像・プロフィール本文は転載しない。リンクと短い要約だけ。

## 出典の書き方(大事)
- 実際に開いて確かめていない LinkedIn のURLは、`src` に入れない(index.html の `selfPost` は linkedin.com/in/ のURLを自動で「本人」の印にするため、未確認のURLが「本人」になってしまう)。
- LinkedIn のURLを出典にしてよいのは、公開ページを実際に開いて本人のものと確かめられたときだけ。開けない場合は、裏が取れた公式・報道のURLを `src` にし、LinkedIn は `note` に「手がかり」として書く。
- 足すだけ・消さない(既存の決めごとと同じ)。
