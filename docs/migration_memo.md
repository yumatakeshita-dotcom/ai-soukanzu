## 毎日の自動更新(2026年11月13日に切り替え済み)
- claude.ai の定期タスク「AI企業の相関図 毎日更新」(毎朝6:43、日本時間)
- **このリポジトリ(main)が正本。** タスクはニュースを調べて site/index.html を更新し、`npm run check` で確認してから main に push する

- PCで作業するときは、始める前に `git pull` で最新を取り込むこと(毎朝自動で更新が入るため)
