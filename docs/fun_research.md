# おもしろ情報(メニュー「おもしろ」)の調べ方(2026/11/21)

起業家・会社の「どうでもよさそうで刺さる話」を5つの欄で見せるページ。画面とデータは `site/data/fun.js`(見本25件)。毎朝の調査が足すものは `inbox/fun/日付.json` → `scripts/fun_merge.py` → `site/data/finds.js` の4行目(`FUN_AUTO`)。毎朝9:13の「調査の新着」(`merge_inbox.py`)が一緒に書くので、公開の手順は今までと同じ。

## 欄
gear(愛用品・服装)/ book(本・映画。人→作品・作者)/ name(社名の由来)/ habit(朝の習慣)/ quote(失敗談・名言)

## 流れ(探すのは Gemini、確かめと取り込みは Claude)
1. 探す: `python3 scripts/gemini_research.py research "テーマ"` を**1日1回まで**。欄を日替わりで回す(月 gear・火 book・水 name・木 habit・金 quote)。相関図にいる人・会社(`site/data/` の人物・会社)から選ぶ。無料枠(1日20回)に注意。ほかの調査を減らさない
2. 確かめる(Claude): 出典のページを実際に開く。クラウドから開けない媒体が多い(Business Insider・Forbes・CNBC など)ので、次の順で:
   - 開ける: SEC(UA必要)、Wikipedia、各社のブログ、x.com(`scripts/x_check.py`)→ `chk:'o'`。名言は**ページの本文に原文がそのまま載っていること**を確かめる
   - 開けないが、複数の報道に載っているのを検索で確かめた → `chk:'s'`(画面に「ページは開けていません」と出る)。**名言の原文は `chk:'s'` では入れない**
   - Geminiが書いたURLは作り話が多い。開けないものは使わない
3. `inbox/fun/日付.json` に足す(下の形)。`python3 scripts/fun_merge.py` で確かめ(足せなかったものは理由が出る)、`npm run check`

## 1件の形
```json
{"cat":"quote","p":"人・会社の名前","en":"英語名","t":"見出し","note":"ひとこと(推測は書かない)",
 "q":"名言の原文(出典と一字一句同じ)","y":"2012","cf":"f","chk":"o","asof":"2026/11/21",
 "src":[["出典の名前","https://…"]],"link":"相関図の会社のキー(任意)"}
```
cf: f=開示(SEC等) o=公式 s=本人 r=報道 / chk: o=ページを開いて確認 s=報道を検索で確認

## 入れないもの
健康・病気・家族・恋愛・資産の細かい話、うわさ、「〜だろう」という筆者の解釈、写真・ロゴの転載(出典へのリンクだけ)。本人・報道が公に語った趣味・習慣の範囲だけ。足すだけで、消さない・書き換えない(直すときは note に「(○月○日に直した)」)。
