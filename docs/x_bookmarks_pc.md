# 祐真さんのXの保存(ブックマーク)・いいねからAI情報を拾う

2026-11-26 追加。他人のいいね・保存はXでは非公開で、クラウドからは見えない。祐真さん本人のものは、PCのChrome(Xにログイン済み)で読める。

## やり方(読むだけ。ボタンは押さない)
1. ChromeのClaude拡張で `x.com/i/bookmarks` を開く(自動で `x.com/i/history` に切り替わる。上のタブ「ブックマーク」「いいね」で切り替え)
2. JavaScriptで `article` を25回ほどスクロールしながら集め、投稿者・日付・本文の冒頭だけを返す(URLのクエリや長いURLが出力に入るとブロックされる。本文のURLは消す)
3. AIの会社・人の動き・出資・買収に当たるものだけ選ぶ。`inbox/moves/`・`inbox/money/` に既にあるか grep で確認
4. 別の出典(報道・公式)を開いて確かめたものだけ `日付-x-bookmarks.json` に足す。確かめられないものは足さない。画像は転載しない
5. ブランチをpushしてPR。マージは本人の「マージして」を待つ

## 2026-11-26 の実績
- ブックマーク約67件・いいね約30件を確認。AIの会社・人の動きは:
  - Epochal(xAI共同創業者3人の新会社、張氏が個人で1億ドル)→ 足した
  - Kotoba TechnologiesのElevenLabsによる買収 → 既に inbox/money にあるので足さず
  - Sierraの Poppy v1.0 公開 → 製品の話で、つながりの追加なし
- ほかは使い方の記事・コツ・日本のスタートアップ記事(newmoなど)で、つながりのデータにならないため見送り
