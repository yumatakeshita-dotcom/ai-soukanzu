# ビジネス化の検討メモ(2026年11月13日の話し合いから)

claude.ai で相関図を作りながら話し合った内容のまとめ。Claude Code で続きを考えるときの前提として使う。

## 1. 相関図をどうビジネスにするか

### 現状の評価
- AI企業の相関図を**そのまま商品にするのは厳しい**
  - 競合が強い(Crunchbase、PitchBook、INITIAL など)
  - AI業界の人事は毎週動くので、更新が止まると価値が落ちる
  - 元が公開情報なので真似されやすい
  - 写真の権利と、実名の人物の記述に注意が必要
- 強み: 日本語で、時間軸と人のつながりが一目でわかる表現は少ない。「つなぐ」営業スタイルとも合う

### 生き残る道(おすすめ順)
1. **発信の武器にする**: X(短く)→ Note(長く)の週1発信で、相関図を図解の素材に使う。相関図で稼ぐのではなく、名前と信用を作る
2. **分野を変えて、自分にしか作れない相関図を作る(本命)**: スポーツビジネス(オーナー・スポンサー・テック企業の買収)、熊本ローカル(飲食・サブカル・スタートアップ)。仕組みはそのまま使い回せる
3. **B2Bで受託・有料化**(2が回ってから): 人材紹介・ヘッドハンター、事業会社の新規事業・提携担当、スポーツクラブ・自治体。月額のアラート配信や、業界別のカスタム相関図の受託

### 最初の2週間でやること
1. 写真の権利を整理する
2. 相関図のスクショ+一言の考察をXに3本出して反応を見る
3. スポーツビジネス版を1社分だけ試作する(例: リバプールのオーナー変遷)
4. 人材紹介・新規事業担当の知り合い2〜3人に「これにお金を払う?」と聞く

## 2. 相関図から見えた「隙間のビジネス」
業界特化AIの波が、まだ「地方」と「スポーツ」に届いていない。
1. ★★★ **地方プロクラブ向け「スポンサー営業AI」**: 地域企業に響く提案づくり、効果測定レポート、更新時期の通知。まずヴォルターズで自分用に作り、他のクラブに売る
2. ★★★ **熊本×台湾の「受け入れ・つなぎ」サービス**: TSMC(JASM)で来た台湾の人・企業と、熊本の店をつなぐ(多言語の店情報、マッチング、福利厚生クーポン)
3. ★★ **日本語の「専門家データ」提供**: AI企業向けに、日本の現場の専門家(スポーツ、飲食、職人など)を集めてデータ作りを請け負う
4. ★★ **AI人材の移籍データ**: 移籍アラートと業界の人の地図を、ヘッドハンター・採用担当に月額で
5. ★ **地方中小企業のAI導入代行**: 競争が多いので、1・2のついでにやる

## 5. Claude と Claude Code の使い分け
- **Claude Code(このリポジトリ)**: データとプログラムの本体。GitHub が正本
- **Claude(アプリ)**: 調べもの、記事・X投稿の下書き、試作
- ルール: **直すのは必ずこのリポジトリ**。アーティファクトだけを直すと、毎朝の自動更新で上書きされて消える
- 移る目安: 有料化・自分のドメイン・SEO・他の人と一緒に作る、のどれかをやりたくなったら、公開先(GitHub Pages など)を用意する

## 6. 公式・開示の数字だけで作る「確かな版」(2026年11月18日に追加)
相関図の線と数字には、2026年11月18日から確かさの印(公式・開示・本人・報道・推定)が付いている。これを売り物の差にする案。

### 何を売るか
- **確かな版の資料**: 会社どうしの取引・出資・人のつながりを、会社の公式発表と法定の開示書類(SEC・EDINET・HKEXなど)で確かめた数字だけでまとめた資料。報道だけの数字は別の欄に「参考(報道)」として分けて載せる
- 相手: 投資・M&Aの担当、営業の企画、取締役会の資料を作る人など、間違った数字を出すと困る人
- 売り文句: 「どの数字も、出どころの書類までたどれる」。1つ1つの数字に出典のURLと確かめた日が付いている

### 形の案(おすすめ順)
1. **1社ずつのレポート(1枚〜数枚)**: 営業資料(共通のつながり→「営業資料(1枚)を作る」)に、印と出典を付けた版。単発で売りやすい
2. **業界ごとの確かな版(計算資源の取引・電力とデータセンター・中国のAI企業など)**: 月1回の更新で定額
3. **データの書き出し(CSV)**: 印と出典の列付き。社内の分析に使う人向け

### いまの手持ち(2026年11月18日時点、重複を除いた線の数)
- 公式 100本、開示 20本、本人 1本、報道 143本(出典のない線は別)
- 毎週日曜10:23の定期タスク「報道だけの数字を確かめ直す 毎週」が、報道だけの数字を5件ずつ確かめ直して、公式・開示を増やしていく

### 作るときに必要なこと
- 画面の「確かさ」で「公式・開示の線だけ」を選んだ状態を、そのまま印刷・PDFにできるようにする
- 資料の最後に、使った出典の一覧(書類名・日付・URL)を自動で付ける
- 「確かめた日」を全部の数字に持たせる(今は説明文に書き足している)
- 注意: 開示書類でも「契約の上限」や「上場前の持ち株」のように条件付きの数字がある。条件も一緒に書く
