# AI企業の相関図

AI企業・半導体企業の人・出資・取引・移籍のつながりを、年ごとに見られる相関図です。

- 本体: `site/index.html`
- 実験ページ(AI相関図ラボ): `site/lab/index.html`
  1. つながり最短ルート
  2. もしTSMCが止まったら
  3. AIマネーの循環
  4. AI人材の移籍マップ
  5. AI人物トレカ
  6. テック長者とスポーツ球団

## はじめて開くとき(Windows)
1. このフォルダを好きな場所に置く(例: `ドキュメント\ai-soukanzu`)
2. PowerShellでフォルダに移動して `claude` と入力すると、Claude Codeがこのプロジェクトを開きます
3. Claude Codeに「サイトを手元で見られるようにして」と頼むと、`npm install` などの準備をしてくれます

## 手元で見る
```
npm run serve
```
ブラウザで http://localhost:8000 を開きます(本体はデータが多いので、開くまで数秒かかります)。

## 変更したあとの確認
```
npm run check
```
すべてのページをパソコン幅とスマホ幅で開き、エラーやはみ出しがないかを確かめます。
