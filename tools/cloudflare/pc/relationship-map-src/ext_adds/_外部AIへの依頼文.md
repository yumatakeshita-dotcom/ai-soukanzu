# 外部AIへの依頼文（ChatGPT・Gemini などにそのまま貼る）

下の「---」から「---」までをコピーして貼ります。`【会社名】` と `【会社キー】` だけ書き換えてください。

---
あなたは企業の人物・出資者の調査を手伝うアシスタントです。
次の会社について、人物・出資者・関連組織を調べ、**下の形式のJSONだけ**を出力してください（説明文は不要。コードブロックで囲む）。

対象会社: 【会社名】（会社キー: 【会社キー】）

ルール:
- 確認できた事実だけを書く。推測・噂・私生活（家族の情報、子どもの話、連絡先）は書かない。
- 各人物・組織に **src（出典のURLまたは媒体名）** と **conf** を必ず付ける。
  - conf は「確認済み」（会社の公式発表・有価証券報告書・公式サイト）、「報道」（Reuters・Bloomberg・日経など）、「未確認」（単一の情報源のみ）のどれか。
- id は英字の小文字とアンダースコアだけ（例: `sam_altman`）。日本語の名前は name に書く。
- kind: 人物は `p`、出資者は `i`、関連組織（子会社・投資先・元社員が作った会社）は `o`。
- from: その役職・関係が始まった西暦（数字）。to: 終わった西暦（在籍中は null）。founder: 創業者なら 1、そうでなければ 0。
- edges の k は `member`（所属）、`invest`（出資）、`from`（出身元）、`moved`（移籍先）、`owns`（親会社・傘下）、`link`（線のみ）から選ぶ。a は人物・組織の id、b は相手の id（会社そのものは会社キーを使う）。
- en には、人物の id → 英語名を入れる。
- 出典が見つからない人は入れない。

形式:
```json
{
  "company": "【会社キー】",
  "en": { "人物のid": "英語名" },
  "nodes": [
    {
      "id": "person_id",
      "name": "日本語名",
      "kind": "p",
      "from": 2025,
      "to": null,
      "founder": 0,
      "role": "役職（短く）",
      "desc": "説明文（2〜3文。日付つきの事実）",
      "src": "出典",
      "conf": "確認済み"
    }
  ],
  "edges": [
    { "a": "person_id", "b": "【会社キー】", "k": "member", "label": "" }
  ]
}
```
---

## 出てきたJSONの使い方

1. 出力を `ext_adds/【会社キー】.json` という名前で保存する（例: `ext_adds/openai.json`）。
2. 検査: `python -I ext_apply.py`（この中の `docs\rooms\relationship-map-src` で実行）。「OK」と出れば次へ。「NG」なら、表示された行を直してもらう。
3. 取り込み: `refresh.py --no-fetch` でビルド → 公開版をCloudflareへ（手順は指示書の「公開の手順（Claude不要）」）。
